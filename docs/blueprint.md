# **App Name**: Bill Bliss

## Core Features:

- Fixed Bills Display: Display fixed bill categories (water, electricity, internet, rent).
- Income Input: Allow users to input total income amount.
- Expense Calculation: Automatically calculate and display total expenses based on entered bills and user inputted income.
- Local Data Storage: Enable persistent storage of financial data for the current session using browser storage (no remote database).
- Spending Insights: Based on past entries, a tool provides personalized spending habit insights.

## Style Guidelines:

- Primary color: Light purple (#B19CD9) to evoke a sense of calm and financial well-being.
- Background color: Very light purple (#F5F0FF), subtly tinted, nearly white, creating a clean, uncluttered backdrop.
- Accent color: Blue-purple (#7B68EE) to highlight important actions and data points.
- Body and headline font: 'Inter' sans-serif for a modern and neutral feel.
- Use minimalist, line-based icons to represent different bill categories.
- Maintain a clean, spacious layout to avoid overwhelming users with too much data at once.
- Incorporate subtle animations on data updates and transitions to enhance user experience.
